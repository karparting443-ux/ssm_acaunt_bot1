# SSM ACCOUNT BOT

Telegram-бот (aiogram 3 + PostgreSQL). Тариф «1 LIMIT»: 10 сомони / 100 руб., 24 ч, 1 аккаунт в час.
Оплата: пользователь шлёт чек, администратор подтверждает кнопкой в Telegram.

## Деплой на Railway
1. Залейте папку в GitHub-репозиторий → Railway → New Project → Deploy from GitHub.
2. В проекте: New → Database → PostgreSQL.
3. В сервисе бота → Variables:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_IDS` — Telegram ID админов через запятую (узнать: @userinfobot)
   - `DATABASE_URL` — `${{Postgres.DATABASE_URL}}`
   - `TZ_NAME` — необязательно, по умолчанию `Asia/Dushanbe`
4. Deploy. Старт-команда: `python main.py` (railway.json / Procfile). Таблицы создаются сами.
5. Запускайте ровно ОДИН экземпляр сервиса (long polling).

## Первая настройка (в Telegram, без правки кода)
`/admin` → «🏦 Реквизиты TJS/RUB» (куда платить) → «➕ Добавить акк.» (склад).
Там же: цены, акк./час (➕/➖), длительность, удаление со склада, остаток склада, вкл/выкл тарифа.

## Как работает
- Оплата подтверждена → подписка на N часов, первый аккаунт сразу, далее раз в час.
- Выдача атомарная (`FOR UPDATE SKIP LOCKED`): один аккаунт не получат двое.
- Все выдачи пишутся в `issue_history`; пользователь видит остаток времени и историю.
- Склад пуст → уведомление всем админам (не чаще раза в 6 ч); выдача догонится после пополнения.
- Через N часов подписка автоматически завершается, пользователю приходит уведомление.
- Смена цены/длительности/акк. в час действует на новые выдачи и новые подписки.
- Повторная оплата при активной подписке продлевает её.
